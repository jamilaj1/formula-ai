عنوان API الأساسي:

BASE https://api.jamilformula.com/v3

المصادقة

كل طلبات API تتطلب مفتاح API يُرسل في الـ header. احصل على مفتاحك من لوحة التحكم → الإعدادات → API Keys.

curl -X GET "https://api.jamilformula.com/v3/formulas/search" \ -H "Authorization: Bearer fa_live_sk_..." \ -H "Content-Type: application/json"

⚠️ أمان: لا تكشف مفتاحك في الكود الأمامي (Frontend). استخدم متغيرات البيئة دائماً.

بحث الفورمولات

البحث الذكي بالذكاء الاصطناعي عن أي فورمولا كيميائية بلغة طبيعية.

POST /formulas/search

المعطيات (Parameters)

الحقلالنوعالوصف
querystringاسم المنتج المراد البحث عنه
categorystringالفئة (cosmetics, detergents, ...)
countrystringكود الدولة لفحص الامتثال (ISO-2)
languagestringلغة الرد (ar, en, fr, ...)

مثال طلب

// JavaScript / Node.js const response = await fetch('https://api.jamilformula.com/v3/formulas/search', { method: 'POST', headers: { 'Authorization': 'Bearer ' + process.env.FORMULA_AI_KEY, 'Content-Type': 'application/json' }, body: JSON.stringify({ query: 'natural shampoo for dry hair', category: 'cosmetics', country: 'SA', language: 'ar' }) }); const data = await response.json(); console.log(data.formulas);

مثال رد

{ "id": "FA-2026-04891", "name": "شامبو طبيعي للشعر الجاف", "category": "cosmetics", "confidence": 0.96, "components": [ { "name": "Sodium Laureth Sulfate", "cas": "68585-34-2", "percentage": 14.0, "function": "Primary Surfactant" }, // ... 8 more components ], "compliance": { "SA": true, "EU": true } }

فحص الامتثال التنظيمي

تحقق من توافق فورمولا مع لوائح أي دولة في العالم.

POST /compliance/check
# Python import requests response = requests.post( 'https://api.jamilformula.com/v3/compliance/check', headers={'Authorization': f'Bearer {os.environ["FORMULA_AI_KEY"]}'}, json={ 'formula_id': 'FA-2026-04891', 'countries': ['SA', 'AE', 'EG', 'EU', 'US'] } ) result = response.json() print(f"Compliant in {result['compliant_countries']} of {result['total']} countries")

استخراج من كتاب

ارفع كتاباً واستخرج الفورمولات منه برمجياً.

POST /books/extract
# Upload book and extract formulas curl -X POST "https://api.jamilformula.com/v3/books/extract" \ -H "Authorization: Bearer fa_live_sk_..." \ -F "file=@./CosmeticFormulary.pdf" \ -F "language=auto" \ -F "complete_missing=true"
